# Model Tides

Browser imports OpenCode SQLite databases and Model Tides v1 metadata JSON locally; legacy Model Currents v1 files remain accepted. Codex and Claude Code JSONL are converted on-device using a local Python script. A Cloudflare Worker serves the app and receives only explicitly approved, Brotli-compressed weekly model/count snapshots; it stores public counts in D1 and renders public pages and Open Graph images. Source transcripts, paths, exact event times, and session/message IDs never enter weekly uploads. The service worker caches only built app assets. The source AG Studio workshop remains a separate repository.

Public contributions keep the exact reviewed model names, including historical IDs and provider-specific aliases absent from current catalogs. The CLI and browser show every week, model, and count before explicit consent; the Worker validates weekly schema, name length and characters, counts, and size limits before D1 writes. No live model catalog is required for uploads. Self-reported names cannot prove actual model use.

The homepage contains the shared graph and a single `npx model-tides@latest upload` command. Until five contributors share a model-week cell, the graph shows clearly labeled mock data. The full private browser import, timeline, and contribution view lives at `/local/` and remains available offline. The repository-root npm package stays private; only the separate `cli/` package provides the published `model-tides` command.
