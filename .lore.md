# Model Tides

Browser imports OpenCode SQLite databases and Model Tides v1 metadata JSON locally; legacy Model Currents v1 files remain accepted. Codex and Claude Code JSONL are converted on-device using a local Python script. A Cloudflare Worker serves the app and receives only explicitly approved, Brotli-compressed weekly model/count snapshots; it stores public counts in D1 and renders public pages and Open Graph images. Source transcripts, paths, exact event times, and session/message IDs never enter weekly uploads. The service worker caches only built app assets. The source AG Studio workshop remains a separate repository.
