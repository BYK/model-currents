# Model Tides

The CLI reads local OpenCode SQLite databases and Codex and Claude Code histories with Node.js; optional Python scripts export private event metadata offline. Legacy Model Currents v1 JSON remains accepted by the CLI. A Cloudflare Worker serves the weekly app and receives only explicitly approved, Brotli-compressed weekly model/count snapshots; it stores public counts in D1 and renders public pages and Open Graph images. Source transcripts, paths, exact event times, and session/message IDs never enter weekly uploads. The service worker caches only built app assets. The source AG Studio workshop remains a separate repository.

Public contributions keep the exact reviewed model names, including historical IDs and provider-specific aliases absent from current catalogs. The CLI shows every week, model, and count before explicit consent; the Worker validates weekly schema, name length and characters, counts, and size limits before D1 writes. No live model catalog is required for uploads. Self-reported names cannot prove actual model use.

The homepage leads with shared weekly counts. Until five contributors share a model-week cell, the graph shows clearly labeled mock data. The browser no longer imports databases or event metadata; `/local` and `/local/` redirect to `/`, and the service worker never caches those routes. Offline export and private history reading remain in the CLI and Python scripts. The repository-root npm package stays private; only the separate `cli/` package provides the published `model-tides` command.
